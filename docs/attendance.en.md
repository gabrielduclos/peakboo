# Attendance confirmations

A transition to Going registers a `confirmed` activity in the same transaction as the RSVP. Repeating the same state does not create notifications. Other group members see the participant and event in the notification center; muted groups suppress this notice. Web Push respects active subscriptions, language and preview preferences. Migration 010 extends the existing constraint without deleting records. Push delivery depends on the device and provider.
