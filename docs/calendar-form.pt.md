# Formulário de compromissos

`src/features/calendar/EventFormDialog.tsx` é a apresentação compartilhada do formulário de criação/edição. Os componentes raiz fornecem valores, grupos, estado pendente e callbacks. A produção mantém a API; a demonstração mantém o armazenamento local. Não há alteração de contrato, dados ou estilo.
